# Gateway runbook

- A gateway serves up to 60 sensors. If several sensors go silent at the same time, check the gateway first.
- Firmware 2.2 drops uplinks after a cold restart. Fixed in 2.3.
- Firmware updates only in planned windows, with an engineer on site or on call.
- Spare gateways are in the Torino office, shelf B.
